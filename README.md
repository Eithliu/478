# 478

Une application desktop pour respirer et s'endormir en moins de temps qu'il n'en faut pour le dire.

## Application version PWA

L'application est disponible gratuitement à l'adresse suivante : [4 7 8](https://478.appwrite.network/)

## Application Desktop, en client lourd.

Cloner le projet,
S'assurer que npm et javascript sont installés.
Assurez-vous que Rust soit également installé sur votre ordinateur.

### En local

```bash
git clone git@github.com:Eithliu/478.git
npm install
npm run tauri dev
```

### Pour avoir l'application Desktop

Pour exporter le projet et le rendre disponible en application de bureau (windows, mac ou Linux),
cloner le projet,
S'assurer que npm et javascript sont installés.
Assurez-vous que Rust soit également installé sur votre ordinateur.

```bash
git clone git@github.com:Eithliu/478.git
npm install
npm run tauri build
```
